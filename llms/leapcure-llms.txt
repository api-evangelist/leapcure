# Leapcure

> Leapcure is a clinical-trial patient recruitment company ("where patient advocacy meets research"). The company itself publishes no product API; the one machine-readable surface it operates is the WordPress REST API behind its blog at blog.leapcure.com. This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's live route metadata and the artifacts in this repository — no operations or facts were invented.

## APIs

- [Leapcure Blog Content API (WordPress REST API wp/v2)](https://blog.leapcure.com/wp-json/wp/v2): Public read + authenticated write over posts, pages, categories, tags, users, media, comments, search, taxonomies, types and statuses. Anonymous read verified 2026-07-19; writes require WordPress application passwords (HTTP Basic).
